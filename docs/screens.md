# 화면 목록 (명세 ID 기준)

> "명세 ID"는 **기능명세서 v1.0의 기능 ID**(예: `RULE-02`, `SCH-04`)를 가리킨다. `docs/API.md`의 `API-RULE-xx`/`API-SCH-xx` 같은 **API ID**와는 접두어는 같아도 번호 체계가 다르니 섞어 쓰지 않는다 (API ID ↔ 기능 ID 매핑은 `docs/API.md` 참고).

| 화면 | 명세 ID | 대상 | 비고 |
|---|---|---|---|
| 근무표 시트 | SCH-01~11 | 수간호사 | 메인. 닫힘/열림 두 버전 |
| 자동 생성 진행 | GEN-02 | 수간호사 | 광고 허용 지면 (AD-01) |
| 생성 실패·해 없음 | GEN-04 | 수간호사 | 우선순위 🔶 |
| 신청 관리 | REQ-02, REQ-04 | 수간호사 | 승인·반려(REQ-02) + 목록 조회(REQ-04) |
| 새 신청 | REQ-01 | 전원 | 연차=필수 반영, 희망 오프=가능하면 반영 |
| 간호사 명단 | NUR-02 | 수간호사 | 필드 차등은 서버 규칙 |
| 간호사 등록 | NUR-01, COM-02 | 수간호사 | 퇴사 상태는 등록 불가 |
| 규칙 설정 | RULE-01~04 | 수간호사 | |
| 통계·공정성 | SCH-04 | 수간호사(전원) / 간호사(본인) | |
| 가입 승인 | AUTH-06 | 수간호사 | 승인 권한은 일반 간호사 고정 |
| 감사 로그 | SEC-03 | 수간호사 | 보기 전용 |
| 병동 설정 | AUTH-05, AUTH-07 | 수간호사 | 코드 재발급(AUTH-05), 권한 이관(AUTH-07) |
| 소속 선택 / 승인 대기 / 병동 개설 | AUTH-03, AUTH-04 | 소속 없음 | 병동 개설(AUTH-03) / 코드로 가입 신청(AUTH-04). 사이드바 없음 |
| 빈 상태 6종 + 일반 간호사 확정 전 | COM-04, SCH-08 | 각각 | SCH-08=확정 근무표 조회(DRAFT 미공개) |

미제작: 퇴사 처리(NUR-06), 규칙 위반 패널(SCH-05), 확정·확정 취소 모달(SCH-07)

## 배치 규칙 (캔버스)
한 줄 5개, 간격 160 이상. 라이트 블록 위, 다크 블록은 같은 모양으로 +7600 아래. 겹치면 재배치한다.

## 프로토타입
사이드바 메뉴 → 각 화면. 버튼 흐름은 [새 신청 → 신청 관리], [간호사 등록 → 안내 창(한 명 더 등록 / 간호사 명단)], [간호사 정보 수정 → 간호사 명단], [소속 선택 → 승인 대기/병동 개설 → 근무표 빈 상태].
시작 지점: 근무표, 첫 화면(처음 가입), 일반 간호사 — 각각 라이트·다크.
