# 디자인 시스템

## 방향
토스 스타일. 메인은 설명 텍스트 없이 엑셀 같은 시트. 왼쪽 열(헤드라인·카드)은 두지 않는다.
메인 컬러는 **버건디 #a65468**이다. 주요 버튼, 사이드바의 현재 위치 표시에 쓴다. 40~50대가 알아보기 쉬운 것이 우선.

## 폰트
Noto Sans KR (Bold / Medium). 본문 최소 16px, 주요 텍스트 17~18px, 제목 30px.

## 색 — 라이트
배경 #ffffff / 카드 #ffffff + 테두리 #e5e8eb / 본문 #191f28 / 보조 #4e5968 / 흐림 #8b95a1
회색칩·입력창 #f2f4f6 / **메인 버건디 #a65468 (연한 배경 #f7e9ed)** / 보조 파랑 #3182f6 (연한 배경 #e8f3ff) / 경고 #f04452

## 색 — 다크
배경 #17171c / 카드 #202027 + 테두리 #33333d / 본문 #f2f4f6 / 보조 #b0b8c1 / 흐림 #8b95a1
회색 #2c2c35 / 파랑 #4593fc (배경 #1d2b44) / 경고 #f04452
다크의 메인 버건디 값은 Figma 다크 화면 기준으로 정한다 (미정).
시트 칸 테두리는 거의 검정 #121216 (밝은 테두리는 눈이 아프다는 피드백).

## 색 사용 원칙 (칩·상태)
- 3단계만 쓴다: 회색(기본·정상), 버건디(핵심·대기·수간호사·차지), 빨강(경고·위험).
- 파랑은 보조색이다. 토요일 표시와 안내성 요소에만 쓰고 주요 버튼에는 쓰지 않는다.
- 초록/노랑/주황/보라 칩은 쓰지 않는다. 정상 상태는 조용하게, 예외만 눈에 띄게.
- 예외: 시트의 D/E/N/OFF/연차 칸 색은 근무 종류 구분 기능이라 유지한다.
- 토요일 파랑, 일요일 빨강 (요일 순서는 월~일).

## 표면·입체 (수간호사 화면 리디자인)
- 앱 바탕은 `canvas` #f6f7f9, 카드는 흰색 + 테두리 #e5e8eb + `shadow-card`. 떠 있는 창(팝오버·확인 창)은 `shadow-pop`.
- 주요 버튼은 버건디 + `shadow-cta`, hover/눌림은 같은 계열의 진한 버건디 `primary-strong` #8e4357. 보조 버튼은 흰 바탕 + 테두리.
- 버튼 모양은 `src/components/ui/buttonStyles.ts` 한 곳에서 정한다 (AdminButton·RnButton·ScheduleButton 공용).
- 필터 칩 선택 상태는 옅은 버건디 바탕 + 버건디 테두리·글자.
- 근무표 칸은 칸 안에 둥근 근무 색 타일로 그린다. 시트 선은 #e5e8eb, 오늘 날짜는 버건디 원.

## 크기·간격
- 버튼 높이 최소 48 (주요 버튼 56), 필터 칩 44, 사이드바 메뉴 52.
- 표 행 72, 헤더 52, 첫 열 굵게, 나머지 열 보조색.
- 섹션 간격 32, 카드 안쪽 여백 28, 카드 사이 24. 가로 안쪽 여백 48.
- 사이드바 240, 화면 1680×1097 (사이드바 닫힘 1440).
- **기준 모니터는 24인치(1920×1080)**. 월간 근무표는 병동 인원(28~30명)이 스크롤 없이 한 화면에 들어와야 한다 (10/27 PM 미팅). 앱 화면은 80% 배율(`ui-zoom`)이라 코드의 px는 화면에서 0.8배로 보인다.
- 한 번에 보이는 선택지는 묶어서 줄인다 (필터는 그룹 구분선). 주요 버튼은 오른쪽 아래/위.

## 사이드바 메뉴 (수간호사)
근무표, 자동 생성, 신청 관리(대기 수 배지), 간호사 명단, 규칙 설정, 통계·공정성 / 구분선 / 가입 승인(배지), 감사 로그, 병동 설정
