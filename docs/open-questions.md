# 미확정 (🔶) — 화면에 확정값처럼 넣지 말 것

- 다중 병동 소속, 교육(ED) 듀티, 기존 소속자의 병동 개설
- 소셜 로그인 제공자, 코드 입력 시도 횟수, 자동 로그아웃 시간, 가입 승인 단계 유지 여부
- OFF 목표 계산식(주휴일 포함 여부 → 4~5일 차이), 필요 인원의 평일/주말/공휴일 구분
- 확정 취소 안내 방식, 잠금 자동 해제 시간, 자동 생성 최대 시간, 진행률 갱신 방식(폴링/SSE)
- 하드 규칙 충돌 우선순위 (가장 중요)
- 신청: 월 건수 제한, 사유 코드 목록, 웹 푸시 방식
- 화면 임시 값: 규칙 값(연속 나이트 3일 등), 사유 목록, 표의 샘플 데이터
