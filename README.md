# frontend
간호사 근무표 자동 생성 서비스 프론트엔드
## 커밋 컨벤션

| 유형 | 상세 |
| --- | --- |
| feat | 새로운 기능 추가 |
| fix | 버그 수정 |
| refactor | 코드 리팩토링 |
| test | 테스트 코드 작성 |
| chore | 기타 자잘한 작업 |
| docs | 문서 추가 또는 수정 |
| delete | 불필요한 코드나 파일 삭제 |
| build | 빌드 관련 파일 및 설정 변경 |

## 브랜치 형식

`커밋유형/#이슈번호`

예:
`feat/#1`

## 커밋 메시지 형식

`유형: 변경 사항 요약`

- 제목은 30자 이내
- 본문은 자유롭게

예:
`feat: 페이지 추가`
